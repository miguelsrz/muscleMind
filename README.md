## Descripción del Proyecto

Aplicacion desarrollada en Java utilizando interfaz grafica Java Swing. Gestor de entrenamientos que permite al usuario crear su cuenta, ingresar sesion, crear rutinas de ejercicios nuevas y visualizarlas, registrar entrenamientos y consultar su historico. Se aplican todos los conceptos de la Programación Orientada a Objetos estableciendo claramente la relacion entre las distintas clases y su uso en la practica.

## Ejecucion

Para visualizar y utilizar la página es necesario descargar los contenidos del repositorio, sea por clonacion o descarga de la carpeta ZIP.

Se corre el Main.java que abre la interfaz grafica de la aplicacion, ya contando con usuarios por defecto creados con rutinas completas para facil uso.
